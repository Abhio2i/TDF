Adding a new platform profile

To add a new platform profile

To create new folders or entities inside the Database Editor, right-click options are available within the Hierarchy Panel. The steps below describe the complete workflow.

1. Creating a New Folder

  1. In the Hierarchy Panel, right-click on any existing profile or category.

  2. A context menu appears with the following options:

  • Add Folder

  • Add Entity

  • Add Profile

  • Paste

  • Rename

  • Delete Profile

  1. Select Add Folder.

  2. A dialog box opens asking for the folder name.

  3. Enter the desired folder name and click OK.

  4. The newly created folder appears under the selected hierarchy.
