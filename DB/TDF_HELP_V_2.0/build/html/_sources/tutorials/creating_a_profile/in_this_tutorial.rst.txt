In this tutorial
================

In this tutorial, you will learn how to create a profile that defines the parameters of a helicopter in a simulation. 

You will:

- Add a profile to the Platform category and configure it to create a helicopter profile.

- Add a profile to the Sensor category to create a radar profile that will be referenced by the helicopter profile.

Prerequisites: None

Key concepts:

- Scenario Manager
- Database Editor
- Tactical Display
- Profile
- Platform Profile
- Sensor Profile
- Inspector
