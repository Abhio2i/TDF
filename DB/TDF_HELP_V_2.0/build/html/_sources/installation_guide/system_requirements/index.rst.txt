System Requirements
======================

1. Operating Systems
---------------------

The *Indigenous Scenario and Sensor Simulation Toolkit* supports the following 
operating systems:

- **Linux (Recommended)**  
  The software is developed and tested primarily on Linux environments, ensuring
  optimal stability and performance.

**Tested Platform:**

- **Distributor ID:** Ubuntu  
- **Description:** Ubuntu 24.04.3 LTS  
- **Release:** 24.04  


2. Hardware Platform
----------------------

The toolkit is optimised to run on high-performance hardware platforms to support
real-time simulation workloads.  
For best results, the following hardware configuration is recommended:

- **Processor: Intel Core i9 14th Gen**  
  Provides the computational power required for complex simulations and high-speed
  data processing.

- **Graphics Card: NVIDIA GeForce RTX 4090**  
  Delivers exceptional graphics performance necessary for real-time rendering and
  high-resolution visual outputs.

- **Power Supply: Corsair AX1600i Digital ATX Power Supply (CP-9020087-NA)**  
  Ensures reliable power delivery for high-load simulation environments, preventing
  instability during intensive operations.

- **Memory: 32GB (1 × 32GB) DDR5 6000 MHz**  
  Offers high-speed memory access, enabling smooth handling of large datasets 
  without performance bottlenecks.

- **Storage: 2TB PCIe 4.0 M.2 NVMe SSD**  
  Provides extremely fast read/write speeds, ensuring quick loading of scenario
  files and seamless simulation performance.

- **Motherboard: ASUS ROG Strix Z790-F Gaming WiFi II (LGA 1700 – Intel 14th/13th/12th Gen)**  
  Ensures full compatibility with modern processors and high-bandwidth peripherals,
  supporting the overall performance of the simulation toolkit.
