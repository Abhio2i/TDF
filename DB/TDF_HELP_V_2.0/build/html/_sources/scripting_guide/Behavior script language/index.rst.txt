Behaviour Script
================

This section explains how behaviour scripts are used within the system to
automate platform creation, GIS operations, and simulation components.

Behaviour scripting allows users to interact with different modules such as
database configuration, GIS canvas operations, and sensor simulation systems.
These scripts help automate tasks like creating entities, plotting GIS objects,
and controlling simulation elements.
